SÉPARATION DES RESPONSABILITÉS
═══════════════════════════════════════════════════════════════════════════

┌─ fem_solver.py ────────────────────────────────────────────────────────────┐
│ • Classe ElasticityFEM2D                                                    │
│ • Cœur du calcul FEM uniquement                                            │
│ • Dépendances: numpy, scipy                                                │
│ • PAS de matplotlib                                                         │
│ • Réutilisable dans autres projets                                         │
│                                                                              │
│ Méthodes principales:                                                       │
│   - .solve(boundary_conditions)     ← Résoudre                             │
│   - .compute_stress()               ← Calculer contraintes                 │
│   - .von_mises()                    ← Contrainte équivalente              │
│   - .get_results()                  ← Exporter tous les résultats         │
└────────────────────────────────────────────────────────────────────────────┘

┌─ visualization.py ─────────────────────────────────────────────────────────┐
│ • Classe ElasticityVisualizer (statique)                                   │
│ • Affichage indépendant du solveur                                         │
│ • Dépendances: numpy, matplotlib                                           │
│ • PAS de solveur intégré                                                   │
│ • Facilement swappable (matplotlib → plotly → autre)                       │
│                                                                              │
│ Méthodes principales:                                                       │
│   - .plot_displacement_and_stress()   ← Vue 2×2                            │
│   - .plot_deformed_geometry()        ← Géométrie déformée                │
│   - .plot_von_mises()               ← Contrainte équivalente              │
│   - .plot_stress_component()        ← σxx, σyy, σxy                      │
│   - .compare_results()              ← Comparer plusieurs cas              │
└────────────────────────────────────────────────────────────────────────────┘

┌─ exemple_simple.py & exemple_avance.py ────────────────────────────────────┐
│ • Cas d'utilisation concrets                                               │
│ • Dépendent de fem_solver.py et visualization.py                          │
│ • À exécuter ou à adapter pour vos besoins                                 │
│ • Point de départ idéal pour apprendre                                     │
└────────────────────────────────────────────────────────────────────────────┘

   from visualization import ElasticityVisualizer

   problem.solve({'bottom': [(1,0)], 'top': [(1,0.02)], ...})
   problem.compute_stress()
